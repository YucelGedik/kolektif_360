# PLC-HMI-20260921-15 — C6 bildirim siniflari / Start engelleri
Kullanici her bildirimde Hata/Uyari/Mesaj turunun acik belirtilmesini istiyor. Mevcut tablo kullanilacak; yeni ekran/katman yok. Bu not gorev tanimidir, uygulama tamamlandi degil.

HATA: gercek PLC ariza bayragi veya FAULT. xAlarmClampLostDuringCut, xAlarmBladeLostDuringCut, xAlarmClampDownTimeout, xAlarmBladeDownTimeout ve xMoveToStartError HATA.14 numarali donus alarmi HATA sinifidir. FAULT900 olup bilinen neden yoksa HATA 'PLC ariza durumunda; ayrintili neden bilgisi mevcut degil' yedek mesaji; sahte sebep uretme. Ariza ekrani+Alarm0+bos liste tutarsizligi giderilmeli. Sayac tanimi aktif HATA sayisi, Uyari/Mesaj sayilmaz; genelFAULT bilinen nedeni tekrar saymasin.
UYARI: bozukluk demek olmayan, mevcut islemi engelleyen kosul. Start istenirken xX_AtStartFALSE -> 'X baslangic konumunda degil'; xY_AtCenterFALSE -> 'Y merkez konumunda degil'; manualModeTRUE -> 'Start icin Otomatik modu secin'; manualPreparationRequiredTRUE -> 'Manuel hazirligi tamamlayin'; bicak sensoru veya asagi komutu aktif -> 'Bicagi kaldirin'. ServoReadyFALSE, heartbeatOKFALSE, VisionReadyFALSE icin Start hazirlik uyarilari; gercek Fault/powerError varsa HATA onceligi. Sifir literal yerine ayarli baslangic/merkez hedefleri ve PLC tolerans boollari kullanilir.
MESAJ: normal bekleme/ilerleme/tamamlanma; kamera verisi bekleniyor, hazirlik tamamlandi, baslangic konumuna donus tamamlandi. Done sonuclarini yeni islem gibi her taramada tekrar kaydetme.

C6 Start engel listesi: Ilk engelde return edip digerlerini gizleme. Gecerli/guncel readback ile tum ilgili engelleri birlikte listele; PLC xStartPermitted nihai otorite, HMI TRUE uretmez. Aktif cevrimde Start uygun degil bilgisini normal durum MESAJI olarak ele al; normal state bekleyislerini alarm yagmuruna cevirme. Uyari gosterimi baglama uygun; kalici 'manuelde' bilgisini her taramada yeni olay diye kaydetme. Baglanti/stale node bilgisi yoksa konum/izin nedeni uydurma; veri eksikligini belirt. Fiziksel Stop anlik bilgisi tam yayinli degil; yeni tag tahmin etme, PLC bagimliligi olarak bildir. Tum kosullar gorunen sekilde uygunsa ama StartPermittedFALSE ise 'PLC Start izni yok; ek kosul bilgisi gerekli' goster, izni asma.
Liste/history icin kosulun ilk olusmasi/kalkmasi takip edilir, her poll satir eklenmez. Reset history silmez. Aktif hata sebebi latched degilse canli sensoru ilk neden gibi sunma.

Sira: once14 C5 donus HATA mesaji + bu C6/H3/H4 katalog ve coklu Start uyarilari. PLC C6: mod degisimi/Start izinlerinin kaynak incelemesi ve gerekli dar duzeltmeler. Sonra C7 normal/eğimli kesim, Stop/ariza/Reset/manuel donus regresyonu ve HTML rehberin guncellenmesi. Fiziksel X/Y limit uc/kontak/PLC mantigi acik saha gorevi olarak kalir.
HMI sonuclari: mesaj/kaynak/tur/gercek tag tetigi listesi ve test kaniti ile geri bildir. Mevcut tasarimi koru.
