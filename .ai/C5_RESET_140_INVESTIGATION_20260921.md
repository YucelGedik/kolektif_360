# PLC-HMI-20260921-13 — C5 Reset sonrasi140 bekleme incelemesi
Kullanici donuste Reset sonrasi takilma bildirdi. Ekran: state140, BusyTRUE AbortedTRUE ErrorFALSE RequestFALSE. C05 export Logic teslimle yorum/bosluk haric ayni. Kesin bekleme nedeni henuz bilinmiyor; ikiStopDone/durus/Stop/jog/feed/retract canli kosullari istendi. PLC state/Busy zorla degistirilmeyecek.
PLC kaynak acigi: xAxisReset := rtReset.Q her state'te servo reset uretiyor;130/140 Reset davranisi ayrica tasarlanmamis. Ancak Reset tek basina mevcut kodda140'a gecis kosulu DEGIL.140'a girisin gercek nedeni sonraki Stop/mod/jog/feed/pnomatik taleplerinden biri olabilir. Reset kaynakli MC_Stop etkisi canli verisiz kesin iddia edilmez. Bu asamada kanitsiz kilit kaldirma yapilmadi.
HMI duzeltmesi:130='Baslangic konumuna donuluyor';140='Baslangica donus durduruluyor / taleplerin birakilmasi bekleniyor'. Bilinmeyen Durum140 metni eksik enum map. BusyTRUE iken AbortedTRUE normal durus evresinde olabilir: terminal REDDEDILDI gosterip islemi tamamlandi sanma. Error/FAULT bilgisi korunarak Busy durumunu oncelikli goster; Aborted ancak BusyFALSE oldugunda terminal iptal/ret sonucudur. HMI Stop/Reset pulse'larinin FALSE yazilarini, sayfa gecisinde jog/pnomatik release davranisini ve gercek readback/loglari kontrol et; mod kilidini kaldirarak state sorununu maskeleme. Yeni hareket otomatik gonderme. PLC Reset duzeltmesi canli bulgu sonrasi ayri teslim edilecek.
